# Declaración de uso responsable de IA

Se utilizó IA como apoyo para proponer la estructura inicial de la API, casos de prueba, scripts de Postman y documentación.

El estudiante debe verificar personalmente antes de entregar:

1. Que la API inicia localmente y responde como se documenta.
2. Que la colección se ejecuta en Postman desde estado limpio.
3. Que TC-001 a TC-014 corresponden con la matriz.
4. Que el modo `CONTRACT_BREAK=1` produce un fallo real en TC-010.
5. Que al corregir el cambio la colección termina satisfactoriamente.
6. Que el repositorio y el PDF no contienen secretos ni datos personales reales.

La evidencia final debe provenir de una ejecución real revisada por el estudiante. La IA no sustituye esa validación.
